# ctx-monitor for Antigravity CLI (`agy`)

## Setup
Run:
```bash
node plugins/ctx-monitor-agy/scripts/setup.js
```
If another `statusLine` is already configured, pass `--replace` after confirming with the user.

## Uninstall
Run:
```bash
node plugins/ctx-monitor-agy/scripts/uninstall.js
```
